# UrbanEase Database - Team Assignments

## Project Overview
This is a college project for the UrbanEase e-commerce database. The project is divided among team members with each person responsible for specific tables and database components.

---

## Team Members & Responsibilities

### Each team member is responsible for:
- ✅ **3 Tables** (as assigned below)
- 📝 **3 Complex Queries** related to their tables
- 🔧 **1 Stored Procedure** related to their tables
- ⚡ **1 Function** related to their tables
- 🎯 **1 Trigger** related to their tables

## Guidelines for Team Members

### Naming Conventions
- **Queries**: Use descriptive names like `get_user_order_history.sql`
- **Procedures**: Prefix with `sp_` like `sp_CreateOrder.sql`
- **Functions**: Prefix with `fn_` like `fn_CalculateCartTotal.sql`
- **Triggers**: Prefix with `tr_` like `tr_UpdateInventoryOnOrder.sql`

### Code Quality Standards
1. ✅ Add comments explaining the purpose and logic
2. ✅ Use proper indentation and formatting
3. ✅ Test thoroughly before committing
4. ✅ Document input parameters and return values
5. ✅ Handle edge cases and errors

### Collaboration
- Use descriptive commit messages
- Review each other's code
- Ask for help when stuck
- Share knowledge and learnings
